4. Chay SETUP_GITHUB_ONCE.bat.
5. Nhap URL repository dang https://github.com/username/HCME_OOS_3257.git
6. Tren GitHub vao Settings > Pages.
7. Chon Deploy from a branch > main > /(root) > Save.
